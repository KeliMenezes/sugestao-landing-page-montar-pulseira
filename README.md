# 📿 Monte sua Pulseira

## 📖 Descrição

Este projeto é uma página web interativa chamada "Monte sua Pulseira", que permite aos usuários personalizar uma pulseira escolhendo cores de miçangas 
e visualizando sua criação em tempo real. Além disso, oferece um formulário de cadastro para coletar informações de clientes, como parte do processo de 
interação e personalização do produto.

Este projeto foi desenvolvido para auxiliar uma aluna do *EmpowerHer* em seu projeto final do curso, servindo como uma landing page demonstrativa. 
Tive a oportunidade de atuar como mentora e colaborar diretamente na implementação e estruturação desta página.

## 🚀 Funcionalidades

- **Escolha de Cores**: Usuários podem selecionar diferentes cores de miçangas para montar a pulseira de sua preferência.
- **Visualização em Tempo Real**: A sequência de cores selecionadas é exibida em tempo real, permitindo ao usuário visualizar o design da pulseira.
- **Limpar Pulseira**: Opção para limpar a sequência atual de miçangas.
- **Salvar e Carregar Pulseira**: Funcionalidades para salvar o design da pulseira e carregar designs salvos anteriormente.
- **Cadastro de Clientes**: Formulário para coletar informações do cliente, como nome, e-mail, endereço, telefone e sugestões.

## 🛠️ Tecnologias Utilizadas

- **HTML**: Estrutura da página.
- **CSS**: Estilização e layout responsivo.
- **JavaScript**: Funcionalidade interativa, manipulação do DOM e lógica de negócios.

## 📋 Estrutura do Projeto

- **index.html**: Contém a estrutura principal da página, incluindo a seção de escolha de cores e o formulário de cadastro.
- **styles.css**: Arquivo de estilos para a página, definindo cores, layout e responsividade.
- **script.js**: Arquivo JavaScript responsável pelas interações do usuário, como adição de miçangas, limpeza e salvamento da pulseira, e validação do formulário.
